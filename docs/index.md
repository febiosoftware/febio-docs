# FEBio Manuals

This site hosts MkDocs conversions of FEBio's manuals, published as a searchable,
versioned static site with [MkDocs](https://www.mkdocs.org/) and the
[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme.

- **[Theory](theory/index.md)** — the FEBio Theory Manual: the mathematical/theoretical background
  for FEBio's constitutive models and finite element formulations.
- **[Studio](studio/index.md)** — the FEBio Studio Manual: user documentation for the FEBio Studio
  GUI.
- **[Features](features/index.md)** — the FEBio Feature Manual: a reference for every feature
  available in FEBio, with its type string, parameters, and description.
- **[Febcode](features/febcode.md)** — the FEBio input file (`.feb`) format reference.

Use the tabs above to browse any of the manuals.
