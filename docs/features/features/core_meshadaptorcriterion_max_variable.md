# max_variable

**Module:** core

**Category:** meshadaptorcriterion

**Type string:** `"max_variable"`

## Parameters

| Name | Description | Default | Range | Units |
|------|-------------|---------|-------|-------|
| `dof` | dof | -1 | $\in \mathbb{Z}$ |  |


## Description

The `max_variable` criterion evaluates elements based on a primary variable’s degrees of freedom. 

The `dof` parameter selects the degree of freedom that defines the variable to inspect.
