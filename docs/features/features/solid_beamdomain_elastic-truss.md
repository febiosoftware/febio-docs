# elastic-truss

**Module:** solid

| Name | Description | Default | Range | Units |
|------|-------------|---------|-------|-------|

## Description

The `elastic-truss` formulation is an extension of the linear truss formulation and allows to use of the standard FEBio elastic materials. 

!!! warning
    This is an experimental feature!
