# relaxation-exponential

**Module:** solid

**Category:** materialprop

**Type string:** `"relaxation-exponential"`

## Parameters

| Name | Description | Default | Range | Units |
|------|-------------|---------|-------|-------|
| `tau` | time constant | 0 | $\gt 0$ | t |


## Description

The material type for this relaxation function is `relaxation-exponential`.

The reduced relaxation function for this material type is given by

\[
g\left(t\right)=e^{-t/\tau}
\]
