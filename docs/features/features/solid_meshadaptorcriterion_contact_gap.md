# contact gap

**Module:** solid

**Category:** meshadaptorcriterion

**Type string:** `"contact gap"`

## Parameters

| Name | Description | Default | Range | Units |
|------|-------------|---------|-------|-------|
| `gap` | gap | 0 | $\in \mathbb{R}$ |  |


## Description

This criterion evaluates the contact gap for all elements that are in contact. 

The `gap` parameter sets contact gap threshold value.
