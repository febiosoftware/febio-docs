## Description

See Section [relaxation-csexp](solid_materialprop_relaxation-csexp.md) for the description of this relaxation function. When the material parameters vary with the distortional strain $K_{2}$, the material type is `relaxation-CSexp-dist-user`.

The definition of $K_{2}$ is given in Section [relaxation-exp-dist-user](solid_materialprop_relaxation-exp-dist-user.md). That section also defines examples of how to specify these functions.
