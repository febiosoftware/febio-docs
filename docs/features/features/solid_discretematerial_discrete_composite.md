# discrete composite

**Module:** solid

**Category:** discretematerial

**Type string:** `"discrete composite"`

## Parameters

| Name | Description | Default | Range | Units |
|------|-------------|---------|-------|-------|
| `mat` | mat |  | N/A |  |


## Description

The `discrete composite` material allows users to combine different discrete materials to create more complex behavior. The net force is the sum of the forces produced by the component materials.
