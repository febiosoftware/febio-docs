# fiber-NH

**Module:** solid

**Category:** material

**Type string:** `"fiber-NH"`

## Parameters

| Name | Description | Default | Range | Units |
|------|-------------|---------|-------|-------|
| `density` | density | 1 | $\ge 0$ | M/L^3 |
| `mu` | mu | 0 | $\ge 0$ | P |
| `fiber` | fiber |  | N/A |  |


## Description

This material type is `fiber-NH`.

The fiber strain energy density is given by

\[
\Psi_{n}\left(I_{n}\right)=\frac{\mu}{4}\left(I_{n}-1\right)^{2}\,,
\]

where $\mu>0$.
