# generation

**Module:** solid

**Category:** materialprop

**Type string:** `"generation"`

## Parameters

| Name | Description | Default | Range | Units |
|------|-------------|---------|-------|-------|
| `start_time` | start_time | 0 | $\in \mathbb{R}$ |  |
| `solid` | solid |  | N/A |  |


## Description

The `generation` property defines a new generation for a [multigeneration](solid_material_multigeneration.md) material. 

The `start_time` parameter is the "birth"-time for this generation.

The `solid`	property defines of the constitutive model for this generation.
