# 1.2 About this document {: #sec:about }

This document discusses how to use the FEBio command line solver and describes the input file format in detail. Chapter [2](../chapter2/2.1-running-febio-on-windows.md) describes how to run FEBio and explains the various command line options. It also discusses the different files that are required and created by FEBio. Chapter [3](../chapter3/3.1-free-format-overview.md) describes the format of the FEBio input file. An XML-based format is used, organizing the data in a convenient hierarchical structure. Chapter _Materials_ gives a detailed overview of the available constitutive models. Chapter [5](../chapter5/5.1-introduction.md) discusses the restart capabilities of FEBio. The restart feature allows the user to interrupt a run and continue it at a later time, optionally making changes to the problem data. Chapter [4](../chapter4/4.1-the-step-section.md) describes the multi-step analysis feature, which allows the user to split up the entire analysis into several steps. Chapter [6](../chapter6/6.1-optimization-input-file.md) explains how to setup and run a parameter optimization problem using FEBio's optimization module. Chapter [9](../chapter9/9.1-before-you-run-your-model.md) provides helpful information for troubleshooting an FEBio model and offers guidelines that help users avoid common problems. Chapter [7](../chapter7/7.1-overview.md) discusses the configuration file, which allow users to customize how FEBio runs on their system. For instance, users can configure the default linear solver that will be used for solving models. Chapter [8](../chapter8/8.1-using-plugins.md) explains how use plugins with FEBio.
