# 2.5 The Configuration File {: #sec:Configuration-file }

As of version 1.2, FEBio uses a _configuration file_ to store platform-specific settings, such as the default linear solver and the list of plugins that need to be loaded at startup. The configuration file uses an xml format to store data and is detailed in Chapter [7](../chapter7/7.1-overview.md). For backward compatibility, it is still possible to run FEBio without the configuration file. In that case, the default settings prior to version 1.2 are used.

_Example:_

```
> febio –i myfile.feb -noconfig
```

The default configuration file needs to be stored in the same location as the executable and named _febio.xml_. Alternatively, the location and the name of the file can also be specified on the command line using the –config option.

_Example:_

```
> febio -i myfile.feb –config /home/my/folder/FEBio/febio.xml
```
