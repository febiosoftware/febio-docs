# 5.2 The Archive Section {: #sec:The-Archive-Section }

The Archive section must be the first sub-element of the _febio_restart _root element. This section defines the name of the binary dump file:

```
<Archive>archive.dmp</Archive>
```

This file will be created by FEBio when requested by the user and contains the solution of the analysis up to the last converged time step.
