# 3.17 Step Section

The analysis can be divided into separate steps, where in each step, different boundary and loading conditions can be applied. Each analysis step is defined via a _step_ section. In each step, the following sections can be defined:

- Control

- Initial

- Boundary

- Loads

- Constraints

- Contact

- Rigid

When a boundary condition, (load, constraint, contact, etc.,) is applied to a step, then this boundary condition (load, constraint, contact, etc.) is only active during that step. Boundary conditions (loads, constraints, contacts, etc.) that are defined in the main body of the file will persist through all the step.

```
<!-- main body of file -->
 ...
<Step> 
 <step id="1"> 
  <Control>
    … 
  </Control>
 </step>
 <step id="2">
   <Control>
    … 
   </Control>
 </step> 
  … 
</Step>

```
