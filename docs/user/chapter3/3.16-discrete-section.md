# 3.16 Discrete Section {: #sec:Discrete-Section }

This section defines the materials used by the discrete elements and assigns these materials to the discrete elements sets defined in the _Mesh_ section. The materials are defined via the _discrete_material _element and the materials are assigned to discrete element sets using the_ discrete _element.

```
<Discrete>
  <discrete_material id="1" type="linear spring">
    <E>1.0</E>
  </discrete_material>
  <discrete_material id="2" type="linear spring">
    <E>2.0</E>
  </discrete_material>
  <discrete dmat="1" discrete_set="springs1"/>
  <discrete dmat="2" discrete_set="springs2">
</Discrete>
```

The _discrete_material _and the_ discrete _elements are defined in more detail below.

## Discrete Materials {: #subsec:Discrete-Materials }

The _discrete_material _section defines a material that can be assigned to a discrete element set. The_ id _attribute defines the material ID and the_ type _attribute defines the material type.

## Discrete Section {: #subsec:Discrete-Section }

After the discrete materials are defined, the materials are assigned to the discrete element sets that are defined in the _Mesh_ section using the _discrete_ element. This element requires two attributes:

<div markdown="1" style="display: flex; justify-content: center;">

| **attribute** | **Description** |
|---|---|
| dmat | discrete material ID |
| discrete_set | discrete element set defined in the_ Mesh_ section. |

</div>

_Example_:

```
<discrete dmat="1" discrete_set="set1"/>

```
